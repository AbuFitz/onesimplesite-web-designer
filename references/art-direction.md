# Art direction and anti-template reasoning

Use this reference when establishing a new visual direction or when a site looks generic despite being technically polished.

## Derive, do not decorate

Start from contrasts inherent in the business. A meticulous restoration studio might feel archival but tactile; an emergency plumber should feel immediate but controlled; a family solicitor may need warmth held inside rigorous structure. Build the visual language from that tension.

Define six connected decisions:

| Decision | Question | Useful output |
|---|---|---|
| Voice | How does this business sound when it is confident? | restrained, candid, spirited, exacting |
| Type | What character should the words carry? | robust grotesk, humanist sans, editorial serif, technical mono |
| Color | What mood supports trust in this category? | warm mineral neutrals with one oxidized accent |
| Geometry | What shapes belong to the work? | strict ruled lines, cropped arches, soft organic masks |
| Imagery | What should visitors feel they have witnessed? | hands at work, finished spaces, precise details, people in context |
| Motion | What physical behavior fits the brand? | quiet reveal, brisk snap, weighted slide, almost static |

Do not select each item independently. The system should tell one story.

## Signature move

Give the site one recognizable move, not ten unrelated tricks. It can be:

- a layout motif derived from a craft, building, landscape, or artifact;
- a distinctive crop or caption system for genuine client photography;
- a typographic transition that expresses the service;
- a navigation or project-browsing behavior useful to the visitor;
- a small recurring detail drawn from the logo or physical environment.

The signature must still work on mobile and must not obstruct reading or conversion.

## Control AI defaults

Treat these as warning signs, not universal bans:

- centered headline + paragraph + two buttons + floating dashboard/photo;
- repeated sets of three equal rounded cards;
- decorative pills above every heading;
- purple/blue gradients, glow blobs, glass panels, and excessive blur;
- every element rounded to the same radius;
- generic sans type with no deliberate scale or line-break control;
- icons substituting for meaningful imagery or explanation;
- one animation pattern applied to every element;
- enormous type used to disguise thin content;
- alternating left/right feature rows with no narrative reason;
- abrupt dark CTA strip pasted into an otherwise unrelated light page;
- stock phrases and fabricated social proof.

If one of these genuinely serves the client, use it intentionally and customize its proportions, content, and behavior. “Different” is not automatically good; coherence, clarity, and memorability matter more than novelty.

## Type, spacing, color, and imagery

Choose fonts by character, language support, licensing, and load cost—not from a fixed fashionable list. Use few roles and enough contrast between them. Tune display line breaks at real viewport widths. Prevent widows where practical, but never insert brittle manual breaks that fail on mobile.

Create a small fluid spacing scale. Let spacing communicate relationships: tighter inside a thought, larger between narrative chapters. Alternate density so the page has tempo. Large blank areas should create emphasis, not look unfinished.

Give colors jobs: canvas, ink, muted ink, surface, rule, accent, and action. Test actual text contrast. Avoid mixing several neutral temperatures. Texture, borders, shadows, and grain should suggest one material world and one light source.

Prefer real client work and people, with permission. If those are unavailable, use commissioned or generated imagery with a defined brief, then carefully licensed editorial stock, then designed graphic compositions when photography would mislead. Never use a random image API in a client-ready result.

## Direction check

Before implementing deeply, ask:

- Could this exact design plausibly belong to five unrelated industries?
- Does the layout reveal what is special about this client?
- Is the first viewport understandable without jargon?
- Is there a memorable moment that does not compete with the CTA?
- Would removing gradients, animation, and mockups leave a strong hierarchy?

If the first answer is yes or the last answer is no, revise the direction.
